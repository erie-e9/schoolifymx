## 📖 Nuestra Visión

Schoolify.mx nace de algo muy simple: cada año, cuando llega el regreso a clases, las familias enfrentan el mismo estrés — listas escolares largas, múltiples visitas a tiendas, filas interminables, falta de tallas en uniformes, gastos fuertes concentrados en poco tiempo y mucha incertidumbre.

**Nuestra misión es eliminar ese estrés.**

Reunimos en un solo lugar todo lo necesario para el ciclo escolar: útiles y uniformes, organizados de forma intuitiva, con precios justos y facilidades de **pago en abonos**. En lugar de buscar y comparar por su cuenta, Schoolify centraliza el proceso.

### ¿Cómo funciona?
1. **Propuestas Inteligentes:** A partir de la lista escolar, generamos la mejor propuesta de útiles del mercado local.
2. **Uniformes a Medida:** Organizamos la confección tomando medidas de forma rápida para un ajuste perfecto.
3. **Beneficios Directos:**
   - 🚫 Evitar recorridos innecesarios y filas.
   - ⏱️ Ahorrar tiempo valioso.
   - 📊 Claridad y transparencia total en los gastos.
   - 💳 Pagos flexibles y diferidos.

### Impacto Social
Más allá del servicio, Schoolify genera un **impacto directo en la comunidad** al crear oportunidades de trabajo para costureras y proveedores locales, fortaleciendo la economía circular de la región.

## 🚀 Tecnologías Principales

El proyecto está construido bajo un entorno de desarrollo moderno y ultrarrápido:

- **Frontend:** [React 19](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
- **Animaciones:** [GSAP](https://gsap.com/)
- **Accesibilidad Offline (PWA):** `vite-plugin-pwa` con Workbox (Caché por 48 horas).
- **Testing:** Vitest & React Testing Library

## 🛠️ Instalación y Uso Local

Asegúrate de tener instalado [Node.js](https://nodejs.org/) y `yarn`.

1. **Instalar dependencias:**
   ```bash
   yarn install
   ```

2. **Entorno de Desarrollo:**
   ```bash
   yarn dev
   ```
   *El sitio estará disponible en `http://localhost:5173`.*

3. **Construcción para Producción (Build):**
   ```bash
   yarn build
   ```

4. **Prueba local del Build (incluyendo PWA):**
   ```bash
   yarn preview
   ```

## 💡 Estrategia B2B para Colegios

### El valor agregado de "Pago en Abonos" en la Inscripción
**¿Cómo podemos integrar el beneficio de 'Pago en Abonos' de Schoolify dentro de la oferta de valor de inscripción de las escuelas?**

El objetivo es que el padre de familia perciba que, al inscribir a su hijo en la institución, **el gasto de útiles y uniformes ya no es un golpe económico de un solo momento**, sino una facilidad que la escuela le gestionó a través de Schoolify. Esta alianza se convierte en una **ventaja competitiva** para la escuela y un gancho atractivo en sus campañas de captación de matrícula y retención.
